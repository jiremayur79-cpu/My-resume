## 📊 Featured Project: UPI Fraud Detection System

### Overview
A machine learning project to detect fraudulent UPI transactions using classification models. The system analyzes 10,000 transactions and identifies fraud patterns with 88.40% accuracy.

### 🎯 Results
- **Best Model:** Random Forest Classifier
- **Accuracy:** 88.40%
- **Precision:** 99.39% (Low false positives)
- **Recall:** 41.22% (Detects fraud cases)
- **F1-Score:** 0.58

### 🛠️ Technologies Used
- **Python 3.x**
- **Scikit-learn** - Machine Learning algorithms
- **Pandas & NumPy** - Data manipulation
- **Matplotlib & Seaborn** - Data visualization
- **Jupyter Notebook** - Development environment

### 📈 Project Workflow

1. **Data Preprocessing**
   - Feature scaling using StandardScaler
   - 80-20 train-test split
   - 8 engineered features

2. **Model Training**
   - Logistic Regression Classifier
   - Random Forest Classifier
   - Hyperparameter optimization

3. **Model Evaluation**
   - Accuracy, Precision, Recall metrics
   - F1-Score calculation
   - Confusion Matrix analysis
   - Classification Report

4. **Visualization & Analysis**
   - Fraud distribution charts
   - Feature importance plots
   - Model performance comparison
   - Transaction analysis

### 📁 Files Included
- `upi_fraud_detection.py` - Complete project code
- `upi_fraud_detection_analysis.png` - Analysis visualizations
- `feature_importance.png` - Feature importance chart

### 🔍 Key Findings

**Top Fraud Indicators (Feature Importance):**
1. Distance from home - 35.7%
2. Transaction amount - 27.6%
3. Time of day - 14.3%
4. Days since last transaction - 14.1%
